# HSG Battle Arena structural graph

## Official interactive Graft export

`viewer/index.html` is the unmodified **self-contained official Graft viz export** (`@nanonets/graft` 0.21.1, upstream trailhq/Graft commit fe30ead). It is generated by the installed build at `/tmp/hsg-graft-build/dist/viz/export.js`, using Graft's own `exportViz` and `dist/viewer` bundle, with `tabs: ["code", "outline"]`. It embeds only the already-sanitized `graph.json` as the Code graph; no raw source, private instructions, deep/context cards or live endpoints are embedded. The public dashboard iframe points at `/usage/graft/viewer/index.html`, served by the integrated exact asset route with its own hash-based CSP and SAMEORIGIN framing policy. The parent dashboard retains its strict CSP with `frame-src 'self'`. This is a static snapshot, not a live Graft service. The upstream MIT license is retained in `UPSTREAM-LICENSE`.

The old custom viewer assets remain for backwards compatibility/test coverage but are no longer used by the dashboard. The official export is regenerated **after** sanitization, never directly from an unsanitized checkout.

Integrated at **/usage/graft** with a visible sidebar link. The backend preloads legacy `graph.json`, `viewer.js`, and `viewer.css` plus the official exported HTML. Its dedicated route does not fall back to the dashboard shell. No new service, account or provider API is needed.

## Actual scope

Refreshed using Graft @nanonets/graft 0.21.1 (upstream fe30ead), structural build only, no --deep. The current repository contains **25 JavaScript source/test files**, all under usage-dashboard: plugin, public app, scripts, src, test, and the graph integration code. All 25 are included: **328 nodes and 885 internal edges**; 58 external/unresolved edges were omitted. There is currently **no battle-game implementation** anywhere in the repository. Documentation, AGENTS.md, HTML/CSS, deployment/configuration files, package manifests and generated JSON are deliberately not structural nodes. The graph is therefore all currently implemented supported JavaScript code, **not a graph of every repository file or of a nonexistent game**.

Graph metadata records the base Git revision **plus working-tree edits** and its generation timestamp; it is a static snapshot, not automatic/live tracking. The official viewer has Code and Outline tabs, searchable nodes, details, and its own force-directed canvas. The older custom file diagram uses fixed positions and remains only as a legacy test fixture. Directed structural dependencies are extracted/inferred, not runtime execution evidence.

## Privacy and rendering

sanitize.mjs rejects paths outside approved code directories, traversal, arbitrary names/IDs/kinds/spans, malformed metadata, duplicate IDs, unsupported relations/confidences, and credential-shaped identifiers. It projects only id/name/kind/path/span and source/target/relation/confidence, dropping signatures, body hashes, summaries, code excerpts and unresolved edge targets. Structural IDs and paths are relative **public code identifiers**, not private agent/session IDs or machine paths.

Legacy custom-viewer tests still prove file dependency joins and nonzero SVG edges. The official exported viewer instead embeds the sanitized graph in a single HTML file with inline scripts/style and a dashboard iframe. Its own CSP must be reviewed as a separate, same-origin frame policy. Source-only tests are not rendered-browser verification.

## Refresh procedure

Use the reviewed, already-built isolated Graft CLI in /tmp/hsg-graft-build/dist/cli.js (not a globally installed tool). Create a fresh temporary directory and copy only vetted .js/.mjs source/test files into it, preserving repository-relative paths. Inspect the whole repository first: if new game source appears, review it and extend the sanitizer's exact path/format allowlist before adding it. Never copy private agent state, credentials, transcripts or AGENTS/MEMORY instructions.

Run the isolated structural build with telemetry disabled, provider keys unset, and Git ignore mutations disabled:

~~~sh
env -u OPENAI_API_KEY -u ANTHROPIC_API_KEY -u GRAFT_API_KEY DO_NOT_TRACK=1 GRAFT_NO_GITIGNORE=1 GRAFT_NO_IGNORE=1 \
  node /tmp/hsg-graft-build/dist/cli.js build "$isolated_source" --no-reuse --no-gitignore --no-ignore
node graft-integration/sanitize.mjs "$isolated_source/graft/.graph/wiring.json" "$(git rev-parse HEAD) + working-tree edits"
node --input-type=module -e 'import { readFileSync, mkdirSync, writeFileSync } from "node:fs"; import { exportViz } from "/tmp/hsg-graft-build/dist/viz/export.js"; const g=JSON.parse(readFileSync("graft-integration/graph.json","utf8")); mkdirSync(process.argv[1]+"/.graph",{recursive:true}); writeFileSync(process.argv[1]+"/.graph/wiring.json",JSON.stringify({...g,meta:{...g.meta,version:1}})); console.log(exportViz({contextDir:process.argv[1],viewerDir:"/tmp/hsg-graft-build/dist/viewer",outDir:"graft-integration/viewer",repoName:"HSG Battle Arena",subtitle:"Sanitized structural snapshot",tabs:["code","outline"]}));' "$isolated_source"
npm test
~~~

Do not build in the real checkout or enable --deep. Check the sanitized schema, source scope, file/node/edge totals and nonzero rendered edges. The fixed viewer HTML route and iframe/CSP handling are integrated; deployment requires reloading the preloaded web assets separately. No service restart, Gateway, tunnel, DNS or other site change is part of graph generation. The temporary Graft build is not a production dependency; losing it requires separately reviewed reconstruction, never a silent install.
