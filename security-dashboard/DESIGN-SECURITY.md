# Security dashboard surface brief

## Scope and mode
Public read-only /security/ interface. Operate: a visitor assesses current evidence, identifies active findings, filters reports, opens sanitized details, and examines each scanner's real execution state. No private artifacts or mutation controls.

## Direction contract
THESIS: An evidence-first worklist, not an alarm wall or a scorecard gallery. Lead with the assessment's uncertainty, then place incident triage before scanner and methodology drilldowns.

OWN-WORLD: Cool mineral light ground, deep slate header, blue-green structural accents, white working surface; rust/red only for severe finding states. Clear system text with tabular numerals, gentle separators, no security-neon or fake telemetry.

STORY: See scan recency and whether recurrence is enabled; read a modest score with explicit confidence; act on current incident reports; inspect source status and rubric only when needed.

FIRST VIEWPORT: Concise title and refresh, compact pending-automation notice, split assessment and three action metrics, direct section navigation, incident search and filters. Signature interaction: disclosure rows turn a dense finding inventory into a progressive sanitized evidence trail without navigation or modal interruption.

FORM: Standard accessible disclosure and native form controls, adaptable two-column assessment above a one-column worklist. Assigned direction seed: none (unavailable: required root PRODUCT.md lies outside delegated write scope and concept-seed refused to run).

FINISH: Frontend tests and manual viewport review if browser available; no claim of live publication from editing disk. Design skill's full repository-level artifact flow could not complete within the delegated frontend-only scope.

## Product constraints
Use /security/api/summary only; no invented incidents, cadence, trends, CVEs, certification, full-repository coverage, or source evidence. Missing scanner data is not a pass. Recurring automation remains pending until owner activation is proved. Native disclosure/summary afford keyboard toggling and Escape is unnecessary because no modal is introduced.
